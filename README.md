# FOGth – G-Root System

## Warum G?
G ist die globale Wurzel, die das alte ABC-System ersetzt.

- A = physische Achse (quant)
- B = narrative Achse (syn)
- C = Wirbel-Achse (WHIRL)

Diese drei bilden eine 3×3-Matrix:

A B C  
B C A  
C A B

## Axiome
- Dualkraft (A + B)
- 3E/6E (A + B + C)
- 360° Rotation (C + A)

## ID = W
W steht für Wurzel, Welt, WHIRL, Wiederkehr.
